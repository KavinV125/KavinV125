I'm an Electronics and Communication Engineering undergraduate at **Bannari Amman Institute of Technology (BIT), Tamil Nadu, India**.

## 🚀 Engineering Projects

### 01. Intelligent IoT Animal Crossing Alert System
**Domain:** Edge AI | Computer Vision | IoT | Wildlife Safety

- Developed an AI-assisted animal detection and alert system.
- Integrated Raspberry Pi 4, YOLOv4, PIR and IR sensors.
- Explored LoRa-based long-range communication.
- Designed the system to detect animal movement and generate alerts near crossing zones.

**Hardware:** Raspberry Pi 4, PIR, IR, LoRa  
**AI:** YOLOv4, OpenCV

🏆 BIT Hackathon Season 1 – 1st Place

### 02. Real-Time IoT Landslide Prediction System
**Domain:** Environmental Monitoring | Wireless Sensor Networks

- Designed a distributed sensor monitoring architecture.
- Slave ESP32 nodes collect environmental parameters.
- LoRa communication transfers sensor data to an Alpha ESP32 master.
- Master communicates with Raspberry Pi through UART.
- Integrated data logging using CSV, MySQL and ThingSpeak.

**Hardware:** ESP32, Raspberry Pi, RF96 LoRa  
**Communication:** LoRa, UART

### 03. FPGA-Based GNSS + IMU Sensor Fusion
**Domain:** FPGA | Verilog | Digital Signal Processing

- Developing a custom synthesizable sensor-fusion hardware architecture.
- Integrating u-blox ZED-F9P GNSS with MPU6050 IMU.
- Exploring Kalman filter implementation using fixed-point arithmetic.
- Designing UART receiver, GNSS parser, I²C controller and FIFO modules.
- Exploring PicoRV32 integration into the FPGA system.

**Technologies:** Verilog, FPGA, PicoRV32, UART, I²C  
**Design:** Q16.16 / Q12.20 fixed-point arithmetic

### 04. Smart IoT Water Quality Monitoring System
**Domain:** IoT | Environmental Technology | Edge Computing

- Working on real-time water quality monitoring.
- Sensor integration for pH, TDS, turbidity and ORP.
- ESP32 and Raspberry Pi-based monitoring architecture.
- Cloud dashboard, database integration and remote monitoring.
- Exploring predictive water-quality analysis.

**Technologies:** ESP32, Raspberry Pi, Node.js, Firebase, MySQL, MongoDB, MQTT

### 05. Non-Invasive Maternal Monitoring System
**Domain:** Biomedical Electronics | Wearable IoT | Sensor Fusion

- Designing a wearable monitoring system for high-risk pregnancy monitoring research.
- Exploring multiple BMX160 IMUs for fetal movement detection.
- MAX30102 for maternal pulse and SpO₂ monitoring.
- TCA9548A I²C multiplexer for multiple IMU integration.
- Exploring local processing using embedded platforms.

**Hardware:** ARIES IoT, VEGA, ESP32, BMX160, MAX30102, TCA9548A

### 06. Smart Palm-Vein Biometric Payment Soundbox
**Domain:** Biometrics | FinTech | Embedded Systems

- Exploring palm-vein-based biometric authentication for payment applications.
- Integrating a binocular 3D recognition sensor with the ARIES VEGA platform.
- Designing an offline wallet-based transaction architecture.
- Exploring Raspberry Pi as a local database server.
- Payment confirmation through OLED/TFT, audio playback and speaker integration.
- Exploring Razorpay test-mode integration and MQTT-based communication.

**Hardware:** ARIES VEGA, Raspberry Pi, Arduino Nano, OLED, DFPlayer Mini  
**Technologies:** Biometric authentication, MQTT, payment APIs

### 07. Namma Route – Smart Public Transport Tracking
**Domain:** Smart Mobility | IoT | Real-Time Tracking

- Exploring real-time public transport tracking for tier-2 and tier-3 cities.
- Low-bandwidth data communication architecture.
- MQTT-based vehicle tracking.
- Compressed JSON payloads and optimized transmission intervals.
- Passenger-oriented transport information system.

**Technologies:** ESP32, MQTT, GPS, Flutter

### 08. Fundamentzz – POS & Billing Application
**Domain:** Software Development | Retail Technology | Embedded Printing

- Developing a POS billing application with multiple user roles.
- Cashier, waiter and parcel workflows.
- Local synchronization and hotspot fallback.
- Thermal printer integration.
- Tamil-language raster-based receipt printing.
- Customer management, expense tracking and table ordering.

**Technologies:** Flutter, Dart, Bluetooth, Thermal Printing

### 09. NammaThalluvandi – Digital Street Food Ecosystem
**Domain:** Startup | Digital Platforms | Local Commerce

- Exploring a digital platform for discovering and listing street food vendors.
- Validated the concept through interactions with 20+ food carts in Coimbatore.
- Working on vendor discovery, digital presence and mobile application concepts.
- Exploring payment gateway integration and business models.

**Technologies:** Flutter, Payment Gateway Integration

### 10. Smartphone-Sensor-Based Autonomous Road Safety Navigation
**Domain:** Sensor-Based Navigation | Embedded Systems
